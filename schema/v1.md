# Posting schema, version 1

One JSON object per file at `postings/<source>/<board>/<external_id>.json`.

| Field | Type | Meaning |
|---|---|---|
| `schema_version` | integer | Shape of this document. `1` |
| `id` | string | `<source>/<board>/<external_id>`: the file's path under `postings/`, minus `.json` |
| `source` | string | `greenhouse`, `lever`, `ashby`, `workable`, `remoteok`, `rendered` |
| `board` | string | The board's slug at that source, as listed in `boards.yaml` |
| `company` | string | Display name |
| `title` | string | Role title |
| `location` | string | Free text, as the board gave it; may be empty |
| `remote` | boolean | Best effort, from the board's remote flag or location text |
| `url` | string | The board's own posting URL |
| `description_text` | string | Plain-text body; empty for a `rendered` posting |
| `description_html` | string, optional | Original HTML body, when the board provides one |
| `posted_at` | string, RFC 3339 UTC, optional | When the board says it was posted |
| `fetched_at` | string, RFC 3339 UTC | When the crawl observed the revision this file holds. An unchanged posting is not rewritten, so this does not move every crawl |
| `status` | string | `open`, or `removed` once a successful crawl of its board no longer lists it |
| `removed_at` | string, RFC 3339 UTC, optional | Set when `status` becomes `removed`; cleared if the posting returns |
| `render_status` | string | `static` for a board API, `rendered` for a page a browser rendered |

A `removed` posting is deleted from the tree once `removed_at` is older than the crawl's
retention window. Its history stays in git.

## Versioning

`schema_version` increments only on a breaking change: a field renamed, removed or retyped, or
the addressing changing. Before a breaking migration lands, the commit before it is tagged
(`pre-v<N>`). A consumer pinned to `main` reads `schema_version` per document; a consumer
pinned to the tag is frozen, including against new postings.

## Board status

`status/<source>/<board>.json`: `source`, `board`, `render_status` (`static`, `rendered`,
`needs_rendering`, `error`), `checked_at`, `posting_count`, and `error` when the fetch failed
or needs rendering.

## Run manifest

`runs/<YYYYMMDDTHHMMSSZ>.json`: `started_at`, `finished_at`, one entry per fetcher (`name`,
`render_status`, `posting_count`, `rejected`, `error`), and `changes` (`written`, `removed`,
`reopened`, `deleted`).
